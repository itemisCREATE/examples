Generic Tracing in Java

Generic tracing gives a generated state machine one notification channel that reports everything it does: entering and leaving the machine, the start and the end of every run-to-completion step, every state entry, exit and transition, every raised event (incoming and outgoing), every variable write and every time event being set or unset. A single observer receives them all and picks what it is interested in.

For more details, please also refer to the Tracing feature of the Java code generator.

It replaces the enterState / exitState pair of earlier releases, which only reported the first two of those kinds. An existing generator model that still names those parameters keeps validating but produces no tracing code at all, so it has to be migrated: 

feature Tracing {
    generic = true
}

The statechart

The model is the light switch used throughout the code generation examples: an event driven state machine with two states, two incoming events, two outgoing events, a brightness variable and a 30 second timeout. It is small enough that the whole trace of a session fits on one screen, and it still exercises every kind of trace event but the machine's own exit.

The observer

The generator adds a getTrace() observable to the machine. A client subscribes an Observer<TraceEvent<LightSwitch, LightSwitch.State, LightSwitch.Feature>> to it and switches on event.getType(). State and feature come back as literals of the machine's own State and Feature enumerations, so nothing has to be parsed out of strings.

Subscribe before calling enter() if entering the machine should be traced too.

Running it

Run Main with Run As → Java Application, or from the command line: 

javac -d bin $(find src src-gen -name "*.java")
java -cp bin itemis.create.examples.tracing.Main

Operating the light prints the machine's whole behaviour, with the run-to-completion steps visible as blocks: 

machine entered
set      BRIGHTNESS = 0
raised   OFF
entered  MAIN_REGION_OFF

Type 'on' or 'off' to operate the light, 'quit' to leave.
on
raised   ON_BUTTON
step {
